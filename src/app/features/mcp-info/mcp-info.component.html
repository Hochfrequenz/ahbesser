MCP-Integration

AHB-Tabellen in deinem KI-Assistenten

Die AHB-Tabellen stehen zusätzlich als MCP-Server (Model Context Protocol) bereit. Damit kannst du die AHB-Daten direkt in deinem KI-Assistenten – etwa Claude, GitHub Copilot oder opencode – abfragen, ohne diese Website zu öffnen.

Was du damit tun kannst

Kurz gesagt: alles, was auf dieser Website geht, geht auch per MCP, nur eben direkt in deinem KI-Assistenten. Zum Beispiel:

  • einzelne AHBs mittels Prüfidentifikator abrufen,
  • über alle AHBs hinweg suchen und filtern,
  • zwei Formatversionen eines AHBs vergleichen.

Der MCP-Server ist wie diese Website kostenfrei nutzbar. Du musst dich lediglich anmelden.

Server-Adresse

Trage in deinem KI-Tool die folgende Adresse als Remote- bzw. HTTP-MCP-Server ein:

{{ mcpUrl }}

Beim ersten Verbinden öffnet sich gegebenenfalls ein Anmeldefenster. Melde dich dort mit deinem gewohnten Hochfrequenz-Konto an (dasselbe Login wie für diese Website, ggf. lässt du dir erneut einen 6stelligen Code per Email zuschicken).

Falls dein KI-Tool beim Verbinden einen Fehler wie „registration failed“ oder „dynamic client registration“ meldet: Aktualisiere das Tool auf die aktuelle Version. Für Claude, Claude Code (ab v2.1.81), VS Code (GitHub Copilot) und opencode ist keine Registrierung nötig. Hilft das nicht, melde dich bei uns.

Einrichtung in deinem KI-Tool

Die genauen Schritte unterscheiden sich je nach Tool. Folge der offiziellen Anleitung deines KI-Assistenten und trage dort die oben genannte Server-Adresse ein:

  • Claude (claude.ai & Claude Desktop - „Custom Connectors")
  • Claude Code (Terminal) 
    claude mcp add --transport http ahb-tabellen {{ mcpUrl }}

    Danach im Claude-Prompt /mcp öffnen und „Authenticate" wählen (öffnet das Login-Fenster).

  • GitHub Copilot in VS Code
  • opencode

    In deine opencode.json eintragen (Repo-Root oder global unter ~/.config/opencode/opencode.json): 

    {{ opencodeConfig }}

    Danach einmalig anmelden:

    opencode mcp auth ahb-tabellen
